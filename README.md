# ✈️ FlyHigh – AI-Powered Airline Overbooking Optimizer

**FlyHigh** is a real-world, enterprise-ready AI web app that helps airlines optimize revenue by smartly predicting passenger no-shows and recommending overbooking strategies.
Designed with a sleek UI, interactive dashboards, and real-life features like payment, date selection, route inputs, invoice generation, and notes — this is more than a project. It’s a SaaS prototype.

## 🚀 Features

✅ AI-powered no-show prediction (Random Forest)  
✅ Animated overbooking simulator (Plotly)  
✅ Safe overflow limits + AI insight engine  
✅ Save models, export CSV reports, generate invoices  
✅ Beautiful gradient dashboard UI (Streamlit + CSS)  
✅ Flight route, date, and time selectors  
✅ Analyst note-taking and download  
✅ Login + CAPTCHA for protected purchases

## 🎯 Tech Stack

- **Python** + **Streamlit** for app + dashboard  
- **scikit-learn** for machine learning  
- **Plotly** for animated visualizations  
- **Custom CSS** for enterprise UI  
- **Git + GitHub** for version control & deployment
